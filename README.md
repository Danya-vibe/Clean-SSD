# Clean SSD

Нативное приложение для macOS, которое показывает, чем занят диск, и помогает безопасно освободить место. Работает как DaisyDisk и встроенное «Хранилище» macOS, но с упором на поиск и очистку кэша.

- **Хранилище** — разбивка диска по категориям, как в «Системные настройки → Основные → Хранилище».
- **Очистка кэша** — находит кэш, журналы и временные файлы системы и программ, удаляет выбранное.
- **Анализ диска** — интерактивная круговая диаграмма папок, как в DaisyDisk, и коллектор для удаления.

Написано на Swift и SwiftUI, без сторонних зависимостей. Нужна macOS 13 Ventura или новее, поддерживаются Apple Silicon и Intel.

## Установка

Готовой подписанной сборки нет, приложение собирается из исходников за минуту. Нужен Xcode или Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/Danya-vibe/Clean-SSD.git
cd Clean-SSD
./scripts/build_app.sh
```

Скрипт соберёт release-версию, нарисует иконку и создаст `build/Clean SSD.app`. Перетащите его в «Программы» и запустите.

Приложение подписано ad-hoc (без сертификата Apple Developer). Если macOS не даёт его открыть, нажмите на нём правой кнопкой → «Открыть».

## Первый запуск и полный доступ к диску

Без полного доступа к диску macOS не пускает программы в часть папок: кэш Safari, Почту, контейнеры приложений, Корзину, резервные копии iOS. Приложение работает и без доступа, но покажет не всё, а в таких местах будет написано «Нет доступа».

Как выдать доступ:

1. Нажмите «Открыть настройки…» в приложении (баннер или рекомендация в «Хранилище»).
2. В «Конфиденциальность и безопасность → Полный доступ к диску» нажмите «+» и выберите `Clean SSD.app`.
3. Перезапустите приложение.

> После каждой пересборки доступ нужно выдать заново: удалить приложение из списка и добавить снова. Так macOS обращается с программами без сертификата разработчика.

## Хранилище

Экран повторяет устройство встроенного «Хранилища» macOS.

**Полоса диска.** Занятое место разбито на цветные деления по категориям, справа — свободное место. Если навести курсор на деление, появится подсказка с названием категории и её размером, а остальные деления потускнеют.

**Рекомендации:**

| Рекомендация | Что делает |
|---|---|
| Очистка кэша и мусора | Показывает, сколько найдено кэша, и открывает экран очистки |
| Автоматическая очистка Корзины | Включает настройку Finder: удалять из Корзины объекты старше 30 дней |
| Локальные снимки Time Machine | Есть, только если снимки существуют. Удаляет их, нужен пароль администратора |
| Полный доступ к диску | Есть, только если доступа нет. Открывает нужный раздел настроек |

**Категории:**

| Категория | Что сюда входит |
|---|---|
| Документы | Домашняя папка: Рабочий стол, Документы, Загрузки, Фильмы и т.д. (кроме перечисленного ниже) |
| Музыка | `~/Music` |
| Почта | `~/Library/Mail` и контейнер Почты |
| Приложения | `/Applications`, `~/Applications`, `~/Library/Application Support`, контейнеры приложений |
| Разработчик | Xcode, Command Line Tools, симуляторы, кэш npm, Gradle, Cargo, `~/.cache` и др. |
| Фото | Медиатеки `*.photoslibrary` |
| iCloud Drive | Локальные копии файлов iCloud Drive |
| Корзина | `~/.Trash` |
| Другие пользователи и общие файлы | `/Users/Shared` и папки других пользователей (если их можно прочитать) |
| macOS | Системный том и служебные тома APFS: Preboot, Recovery, Update |
| Системные данные | Всё остальное: используемое место минус все категории выше |

Кнопка **ⓘ** открывает подробности категории:

- **Папки и файлы** — самые крупные элементы по размеру;
- **Большие файлы** — отдельные файлы от 100 МБ;
- у каждого элемента при наведении есть кнопки «Показать в Finder» и «Переместить в Корзину».

Для «macOS» показываются тома APFS. Для «Системных данных» показано, из чего они состоят: кэш, журналы, файл подкачки, освобождаемое место.

Цифры почти совпадают с системными. Небольшое расхождение возможно в «Приложениях» и «Системных данных»: Apple распределяет Application Support по своим закрытым правилам.

## Очистка кэша

Приложение ищет кэш в известных местах, считает размер и показывает список по группам. Отмеченное удаляется кнопкой «Очистить» (⌘↩).

| Группа | Где ищет |
|---|---|
| Системный кэш | `/Library/Caches/*` — удаление после запроса пароля администратора |
| Кэш приложений | `~/Library/Caches/*`. Имена и иконки программ определяются автоматически |
| Кэш изолированных приложений | `~/Library/Containers/*/Data/Library/Caches`, `~/Library/Group Containers/*/Library/Caches` |
| Браузеры | Safari, Chrome, Яндекс Браузер, Edge, Brave, Opera, Vivaldi, Arc, Chromium, Firefox |
| Кэш Electron-приложений | Slack, Discord, VS Code, Cursor, Notion, Figma, Telegram Desktop и др. |
| Инструменты разработчика | Homebrew, pip, Poetry, npm, Yarn, Bun, pnpm, node-gyp, CocoaPods, SwiftPM, Gradle, Maven, Cargo, Go, Composer, JetBrains, Playwright, Conda, `~/.cache` |
| Xcode и симуляторы | DerivedData, кэш Xcode, DeviceSupport, кэш симуляторов, превью SwiftUI, документация, архивы |
| Журналы и отчёты о сбоях | `~/Library/Logs`, `/Library/Logs` |
| Временные файлы | Временная папка пользователя (файлы старше 3 дней), кэш macOS пользователя (старше 7 дней) |
| Загрузки и установщики | Вложения Почты, прошивки iPhone/iPad, `.dmg` / `.pkg` / `.ipsw` / `.xip` в «Загрузках» |
| Корзина | `~/.Trash` |
| Резервные копии iOS | Локальные копии iPhone и iPad, с названием устройства и датой |

Пометки в списке:

- **Без пометки** — безопасно, данные создадутся заново. Такие элементы выбраны по умолчанию.
- **«Проверьте»** — удалять можно, но это может стоить данных или времени: архивы Xcode, `~/.cache` (там бывают скачанные модели), резервные копии iOS, установщики. По умолчанию не выбраны.
- **«Запущено»** — программа сейчас открыта, её кэш по умолчанию не выбран. Лучше закрыть программу перед очисткой.
- **Замок** — нужен пароль администратора (системный кэш и журналы).
- **«Нет доступа»** — нужен полный доступ к диску.

Корзину приложение не выбирает само, её нужно отметить вручную.

Переключатель **«Перемещать в Корзину»** отправляет файлы в Корзину вместо удаления. Место тогда освободится только после её очистки.

После очистки приложение показывает, сколько места освобождено и сколько объектов удалить не удалось (например, их защищает система).

## Анализ диска

1. Выберите, что сканировать: весь диск, домашнюю папку или любую папку.
2. Слева — список содержимого с размерами, справа — круговая диаграмма. Каждое кольцо — следующий уровень вложенности.
3. Клик по сегменту-папке открывает её, клик в центр возвращает на уровень выше. Наведение показывает имя, размер и долю.
4. Файлы и папки можно перетащить из списка в **коллектор** внизу окна или добавить через контекстное меню.
5. Кнопка «Удалить» перемещает содержимое коллектора в Корзину или удаляет навсегда, если выключить переключатель.

Мелкие файлы (меньше 128 КБ) собраны в одну строку «Мелкие файлы». При сканировании всего диска показывается **скрытое пространство**: системный том, снимки, освобождаемое место и папки без доступа.

Сканирование параллельное (`fts`), не выходит за пределы тома и не считает дважды жёсткие ссылки. Примерно 280 тысяч файлов (90 ГБ) обрабатываются за 10–15 секунд.

## Безопасность

- В очистке кэша удаляется **содержимое** папок кэша, сами папки остаются, чтобы программы не ломались.
- Корневые и системные пути (`/`, `/System`, `/Library`, `/Users`, домашняя папка, Документы, Рабочий стол и т.п.) удалить нельзя, эта проверка встроена в код.
- Системные пути внутри `/System`, `/usr`, `/private/var/db`, `/private/var/vm` защищены и в анализаторе.
- С правами администратора приложение удаляет только внутри `/Library/Caches` и `/Library/Logs`. Пароль запрашивает сама macOS, приложение его не видит.
- Символические ссылки не обрабатываются: нельзя случайно удалить то, на что они указывают.
- Перед любым удалением показывается подтверждение с итоговым размером и предупреждениями.

## Режим командной строки

Эти команды только читают диск и ничего не удаляют:

```bash
# Найденный кэш по группам
.build/release/CleanSSD --report

# То же и самые большие папки указанного пути
.build/release/CleanSSD --report --scan ~/Library

# Разбивка диска по категориям «Хранилища»
.build/release/CleanSSD --storage
```

Есть переменные окружения для отладки интерфейса:

| Переменная | Что делает |
|---|---|
| `CLEANSSD_TAB` | Открывает нужный раздел при запуске: `storage`, `cache` или `analyzer` |
| `CLEANSSD_SNAPSHOT` | Окно сохраняет снимок самого себя (и данные о раскладке) в указанный файл, затем приложение закрывается |
| `CLEANSSD_SNAPSHOT_DELAY` | Через сколько секунд делать снимок (по умолчанию 6) |
| `CLEANSSD_HOVER` | Сразу показывает подсказку над делением полосы, например `documents` |
| `CLEANSSD_DETAIL` | Сразу открывает окно подробностей категории, например `applications` |

## Частые вопросы

**Безопасно ли удалять кэш?**
Да, если он без пометки «Проверьте»: программы создадут нужные файлы заново. Первый запуск после очистки может быть чуть медленнее.

**Почему после очистки не освободилось место?**
Скорее всего, включено «Перемещать в Корзину». Очистите Корзину.

**Почему некоторые размеры «Нет доступа» или 0?**
Не выдан полный доступ к диску, или он выдан старой сборке. Выдайте его заново и перезапустите приложение.

**Почему цифры немного отличаются от системного «Хранилища»?**
Apple распределяет данные программ между «Приложениями» и «Системными данными» по закрытым правилам. Остальные категории совпадают.

**Что такое «Системные данные» и почему их так много?**
Это кэш, журналы, файл подкачки, снимки Time Machine и служебные данные программ. Часть можно освободить на экране «Очистка кэша». Снимки Time Machine удаляются из рекомендаций.
